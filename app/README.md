# App

Expo / React Native client, including web. The working technical name is `sidehustle`. Final branding is not chosen.

Product decisions live in [`/docs`](../docs/README.md). This package does not yet contain product screens.

```bash
npm install
npm run web
```

Verified with Node 22. This machine also has Node 21 as the default `node` on some shells. If install or start fails, switch to Node 22 and retry.
