# V1 roadmap

**This cut is provisional.** It is a first draft so later work does not treat every idea in `/docs` as a launch requirement. Change this file when the cut changes. Do not treat it as a commitment.

The test for the first usable version is the [core loop](../product/core-loop.md): a person, starting from the [founder fixture](../product/founder-fixture.md), can set a goal, see what to do next, do it, record the money honestly, and get another useful suggestion.

## Core V1

Required to exercise that loop. Still subject to shrinking if a piece is not actually required.

- Authentication, mechanism still [open](../technical/architecture.md). A returning user needs an account. Do not build a login UI before the mechanism is chosen, and do not ship the loop with no way back to the same data.
- Onboarding that produces a money goal and real opportunities, not an empty profile. See [onboarding](../screens/onboarding.md).
- Money goal with realized progress. Expected and potential stay visible and do not fill the goal.
- Opportunities of the four types, with a next action and the conceptual status filters.
- Actions on an opportunity, and a way to record that one was done.
- Recording a financial outcome in the correct layer (realized, expected, potential).
- Home: goal hero, "what should I do now?", and money in motion.
- A basic Discover path that can create an opportunity from a prompt the user answers. Not every guided session below.
- XP for meaningful actions, using a temporary scale. The table in [gamification](../product/gamification.md) is a sketch, not the spec to hard-code forever.
- A handful of achievements tied to real milestones. The example names are not the catalog.
- Progress: lifetime impact by type, the current goal, and XP / level in some simple form.

## Likely V1

High-value, and probably worth including if the core loop is in place. Not required to prove the loop once.

- The rest of Home: weekly momentum, opportunity snapshot, one proactive suggestion, recent wins.
- Domain-specific stage display on opportunity detail, once the stage lists are refined.
- Needs-attention flags. Exact rules still open.
- Opportunity sorts, including a simple "recommended" once there is enough profile data to be honest.
- Guided Discover sessions beyond a single basic prompt: Money Hunt, Skill Miner, Network Scan, Money Recovery, Expense Audit, Quick Wins. These can land one at a time.
- Discover feedback (interested, not for me, already doing this, too much effort, not enough return, never suggest this).
- Weekly quests.
- Settings for profile, goal, personalization, and account export/delete.
- Modest notifications: needs attention, weekly recap, untouched opportunity.
- Simple impact-over-time chart on Progress.
- Personal bests, and a plain "what works for you" once there is history.
- Activity history on an opportunity.

## Open scope

**Friends, leaderboards, and challenges are not placed.** They may be part of V1 or the next slice after the core loop is usable. Privacy defaults are already decided either way. Do not start this surface until this section is resolved. See [social](../product/social.md).

Also still open inside the items above: auth mechanism, production database, API contract style, XP numbers, stage lists, recurring-savings accounting after the first month, net versus gross, and default currency.

## Later

Do not block the first usable version on these.

- Native iOS and Android builds.
- TestFlight or a mobile waitlist.
- Bank, accounting, payroll, or marketplace integrations.
- A separate recommendation service.
- Polished shareable recap pages.
- Public profiles, feeds, comments, or follower mechanics.
- Daily-streak systems. A single non-punitive achievement may exist eventually; it is not a product pillar.
- Anything that turns opportunity detail into a general task manager, or Progress into an accounting dashboard.

## Suggested manual scenario

When a slice is ready to try, walk the founder fixture through it:

1. Set an October-style goal (the month is just the example period).
2. Capture the freelance proposal as potential Earn, the €250 friend repayment as expected Recover, the jacket and outfit as potential Sell, and subscriptions as a Save opportunity with no realized amount yet.
3. Ask for a 30-minute action and get "research the Versace resale value," or an equally concrete existing action.
4. Complete that action, gain XP, and see that realized money did not move.
5. Record the friend repayment as received and see only that €250 move the goal.
6. Cancel a €20 subscription in the scenario and see €20 count, with €240 annualized shown separately.
