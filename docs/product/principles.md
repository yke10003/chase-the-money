# Principles

These are agreed V1 product principles. They are decisions, not a backlog.

1. **Real money is the primary outcome.** A euro goal outranks XP on Home and in the story the product tells.
2. **XP represents effort and progress, not wealth.** XP is not a replacement currency for money.
3. **The app should tell the user what to do next.** Recording activity is not enough. The useful test is: if the user has 30 minutes right now, can the product name something financially useful to do?
4. **Potential money is never treated as realized.** A proposal, a listing, or a hoped-for sale does not move the realized goal.
5. **Earn, Sell, Recover, and Save stay distinct.** Reporting must not collapse them into one interchangeable "money" bucket. €100 saved is not the same event as €100 earned.
6. **Reward execution more than planning.** Creating or planning something earns less recognition than moving it forward or finishing it.
7. **Prefer weekly momentum over punitive daily streaks.** A person with a normal job may only hustle a few days a week. Losing a daily streak must not make the product feel like a punishment. A daily-streak achievement may exist later; it is not the center of the product.
8. **Personalization should improve recommendations.** Skills, time, preferences, past results, and explicit rejections should change what Discover and Home suggest.
9. **Discover creates opportunities, not content consumption.** It is not an article feed.
10. **Progress strong opportunities before generating more.** New ideas are not automatically more valuable than the next action on something already in motion.
11. **Social creates accountability without forcing financial disclosure.** Exact amounts and opportunity names are private by default.
12. **The product is useful with no marketplace, employers, banks, or third-party integrations.**
13. **No bank connection in V1.**
14. **Self-reported results are acceptable for V1.** The user records what happened. The product does not need to verify it against a bank or invoice system.
15. **Desktop web is a first-class experience.** Do not ship a phone layout stretched across a desktop window and call that the web product.
16. **Keep a path to native mobile.** The client is Expo / React Native, not a separate React-only website.
17. **Do not become accounting software or project-management software.** Opportunity detail connects an action to progress and a financial outcome. It is not a generic task manager.
18. **Do not add complexity before the core loop is useful.**

When a later change conflicts with one of these, update this file and add a decision record. Do not leave both versions in the docs.
