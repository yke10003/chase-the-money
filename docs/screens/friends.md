# Friends

**Not implemented.** Product intent only. The navigation item is marked "Soon". The page explains, without sample data, what Friends will be: a small crew, shared challenges, and privacy by default. There is no leaderboard and no list of people.

**Open.** Whether this ships in the first usable version or immediately after the core loop. Do not build it until that scope decision is made. See [roadmap/v1.md](../roadmap/v1.md) and [social](../product/social.md).

## Purpose

**Decision.** Accountability and competition. Not a social network.

Out of scope:

- general posting
- follower counts as a goal
- comment threads
- public financial profiles

## What a friend can see by default

**Decision.**

- goal percentage
- XP
- level
- achievements
- wins the user selected

Exact money and opportunity names stay private unless the user opts in.

## Leaderboards

**Decision.** Primary ranking is goal progress percentage.

**Assumption.** XP is secondary. A money leaderboard is optional and off unless people have agreed to share amounts.

## Challenges

**Assumption.** Initial types could be:

- an absolute money goal
- personal goal progress
- an XP target
- an action-count target
- a specific mission

Examples: make €500 this month; hit 100% of a personal November goal; earn 300 XP this week; list 3 things; contact 5 people in your network.

**Assumption.** A finished challenge can show collective realized impact, for example "Together you generated €1,600." Do not add potential money into that sentence. Privacy for people who have not shared exact amounts is unsolved. See [social](../product/social.md).

## Onboarding

Social setup is optional and late. Skipping it must still produce a useful Home. See [onboarding](onboarding.md).
